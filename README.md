# litepddvideo

Генератор вертикальных (9:16) 3D-роликов с разбором вопросов ПДД для TikTok.
Каждый ролик описывается JSON-сценарием: сцена, машины и пешеходы с траекториями, камера, подписи, карточка вопроса, текст озвучки.
Движок на Three.js рисует любой момент времени детерминированно; `render.mjs` снимает кадры через headless Chromium и собирает mp4 через ffmpeg.

## Запуск

```bash
npm install
npm run preview -- scenarios/q01_ravnoznachny.json     # 540x960, быстро, для проверки
npm run render  -- scenarios/q01_ravnoznachny.json     # 1080x1920, финал
npm run render  -- scenarios/q01_ravnoznachny.json --preview --frames 1,10,20   # только PNG-кадры в out/frames/
npm run voiceover -- scenarios/q01_ravnoznachny.json   # текст озвучки с таймкодами
```

Требуются Node 20+, ffmpeg и Chromium (путь переопределяется `CHROMIUM_PATH`, по умолчанию `/opt/pw-browsers/chromium`).
Без видеокарты рендер идёт через программный WebGL (SwiftShader): ~0,4 с/кадр в превью. На сервере с GPU уберите `--use-angle=swiftshader` в `src/render.mjs`.

## Озвучка

1. `npm run voiceover -- scenarios/<имя>.json`: текст по фразам с таймкодами.
2. Озвучьте в платном сервисе (живой голос, единым файлом).
3. Положите результат в `audio/<имя сценария>.mp3`: рендер подмешает его автоматически.
4. Если длительность фраз не совпала с таймкодами, поправьте `t0/t1` фраз, `labels`, `camera` и траектории в сценарии (тайминги везде в секундах).

## Формат сценария

| Поле | Что делает |
|---|---|
| `duration`, `tag` | длительность (с) и плашка сверху |
| `scene.roads` | `["x","z"]` крестовой перекрёсток, `["z"]` одна дорога с севера на юг |
| `scene.crosswalks` | координаты `z` пешеходных переходов |
| `scene.signs` | знаки: `type` = `main_road`, `yield`, `stop`, `ped_crossing`, `pos: [x, z]`, `rot` в градусах |
| `objects` | `type`: `car`, `bus`, `truck`, `pedestrian`; `color`; `path`: точки `{t, x, z, ease?, ctrl?}`; `ctrl` задаёт изгиб (поворот) |
| `highlights` | пульсирующее кольцо вокруг объекта |
| `routes` | подсвеченная линия на земле |
| `camera` | ключевые кадры `{t, pos, look, fov}` с плавной интерполяцией |
| `hooks`, `labels`, `voiceover` | крючок, подписи над объектами, текст озвучки (он же субтитры). Цвета в тексте: `[y]`, `[g]`, `[r]` |
| `card` | карточка вопроса: `windows` (когда показывать), `reveal` (когда подсветить ответ), `correct` |
| `cta` | финальный призыв |

Координаты: метры, `x` вправо, `z` на зрителя, ось вверх `y`. Движение правостороннее: по полосе `x=+2` едут на север, `x=-2` на юг, `z=+2` на восток, `z=-2` на запад.
