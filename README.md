# litepddvideo

Генератор вертикальных (9:16) 3D-роликов с разбором вопросов ПДД для TikTok.

**Процесс:** сценарий (JSON) → вы записываете голос в Telegram → бот чистит звук, режет запись на фразы, подгоняет под неё анимацию и присылает готовый mp4.

## Telegram-бот

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен. Свой Telegram ID узнайте у [@userinfobot](https://t.me/userinfobot).
2. На сервере (Docker + Docker Compose):
   ```bash
   git clone <репозиторий> && cd litepddvideo
   cp .env.example .env      # впишите BOT_TOKEN и ALLOWED_IDS
   docker compose up -d --build
   docker compose logs -f    # должно появиться «Бот @… запущен»
   ```
   Бот отвечает только ID из `ALLOWED_IDS`. Всё сохраняется в `./data` (сценарии, записи, видео).
3. В Telegram: «🎬 Создать видео» → пришлите сценарий (текстом или файлом `.json`) → бот покажет фразы озвучки.
4. Запишите **одно голосовое** с фразами по порядку, между фразами пауза 1–2 секунды молча. Можно прислать аудиофайл или **видеозапись экрана с голосом** (звук берётся из видео). Telegram не отдаёт боту файлы больше 20 МБ: присылайте запись как «Видео», а не как «Файл», тогда Telegram её сожмёт.
5. Бот очистит запись и пришлёт её обратно с кнопками **«✅ Всё хорошо, делать видео»** и **«🎙 Перезаписать»**. Пока вы не подтвердите, рендер не начинается. Новая запись просто заменяет прежнюю. После подтверждения ролик встаёт в очередь, и бот присылает видео. Под видео кнопки: «🎙 Перезаписать озвучку», «🖥 Full HD».
   «🧪 Черновик без голоса»: проверить сцену до записи голоса.

Если число найденных фраз не совпало с ожидаемым, бот скажет об этом, запишите заново с более заметными паузами.

### Качество картинки и скорость (4 ядра / 6 ГБ, без видеокарты)
Сцены реалистичные: HDRI-небо и мягкие тени, PBR-текстуры асфальта, плитки, бордюров и газона (Poly Haven, CC0), панельные дома с окнами и балконами, процедурные деревья (EZ-Tree), фонари, кусты, гидранты, скамейки, знаки и светофоры в натуральную величину. Свечение фар и сигналов, глубина резкости на главном объекте, сглаживание (рендер в 1,5 раза крупнее).

| Качество | Время кадра (замер, 4 ядра) | Ролик ~40 с |
|---|---|---|
| `draft` 540×960, 15 кадров/с, без эффектов | ~2,7 с | ~30 мин |
| `hd` 720×1280, 30 кадров/с (по умолчанию) | ~2,4 с на общих планах, ~3,9 с с глубиной резкости | ~1–1,2 ч |
| `fhd` 1080×1920 | примерно в 2,2 раза дольше hd (оценка) | ~2,5 ч |

Глубина резкости включается только на планах «на объект» (камера следит за объектом или смотрит на него), на общих планах она почти не видна, а стоит ~40% времени кадра. Вручную: `"dof": true/false` у ключа камеры.
Затенение в углах (AO) даёт ещё +60% ко времени кадра: `RENDER_AO=1`. Рендер идёт в одной вкладке: программная видеокарта и так занимает все ядра, а вторая вкладка только замедляет (замер: 4,1 с/кадр против 9,3 с/кадр) и занимает ещё ~2 ГБ памяти. `RENDER_WORKERS` в `.env` задавать не нужно.
Ресурсы Poly Haven скачиваются при сборке Docker (`scripts/fetch-assets.mjs`, список в `assets/manifest.json`); без Docker: `node scripts/fetch-assets.mjs`.

### Чтобы сервер не забивался
- Сырая запись голоса и промежуточные файлы удаляются сразу после обработки.
- Ролики хранятся `RETENTION_DAYS` дней (по умолчанию 7), потом удаляются сами (проверка при запуске, раз в 6 часов и перед каждым рендером).
- Если свободного места меньше `MIN_FREE_GB`, перед рендером чистка идёт агрессивнее; если меньше 1 ГБ, бот откажется рендерить и скажет об этом.
- Рендер ограничен 45 минутами: зависший не держит память вечно. Очередь не больше `MAX_QUEUE`.
- Контейнер ограничен по памяти (`mem_limit`), логи Docker по 10 МБ × 3.
- Команда `/disk` в боте показывает свободное место, размер данных и память.
- Раз в месяц на сервере полезно: `docker image prune -f` (старые образы после пересборок).

### Озвучка на сайте ElevenLabs вручную
Для бесплатного тарифа или голосов, недоступных через API. После сценария нажмите **«📋 Текст для ElevenLabs»**: бот пришлёт текст фраз с метками пауз `<break time="1.5s" />` (произношение уже исправлено по словарю). Вставьте его на сайте ElevenLabs (модель Eleven Multilingual v2), скачайте mp3 и пришлите боту: он разрежет озвучку по паузам и пришлёт на подтверждение, как голосовое.

### Фоновая музыка
Во всех роликах тихо играет музыка (`assets/music/default.mp3`): примерно на 19 дБ тише голоса (`MUSIC_LUFS=-35`), под голосом приглушается ещё сильнее, паузы тишины внутри трека вырезаются, начало и конец плавные. В боте **«🎵 Музыка»** (`/music`): выключить или включить, заменить трек своим (пришлите mp3, лучше без слов), вернуть трек по умолчанию. Для отдельного ролика: `"music": false` в сценарии. В командной строке: `--music файл.mp3` или `--no-music`.

### Автотест бота
`node test/e2e-bot.mjs` поднимает поддельный Telegram и проходит весь диалог: сценарий → голос → перезапись → подтверждение → видео (рендер в черновом качестве, около 2 минут).

### Озвучка голосами ElevenLabs (свой клон или готовые голоса)
1. Впишите в `.env` ключ `ELEVENLABS_API_KEY` и перезапустите бота.
2. **«🧬 Клонировать голос»** (или `/clone`) → пришлите запись своего голоса (mp3, голосовое или видео; лучше 1–2 минуты, минимум 10 с, без обработки). Бот создаст клон в ElevenLabs (нужен платный тариф с клонированием) и пришлёт пробную фразу.
3. **«🗣 Голоса»** (или `/voices`) → **«➕ Голос ElevenLabs по ID»** → пришлите ID голоса или ссылку на него. Бот проверит голос через API, добавит в список и пришлёт пробную фразу. Голос из общей библиотеки ElevenLabs (Voice Library) сначала добавьте к себе («Add to my voices»), иначе API его не отдаст.
4. В «🗣 Голоса» выбирается **активный голос** (✅), им озвучиваются ролики по умолчанию; 🗑 убирает голос из списка бота (в ElevenLabs он остаётся). Список хранится в `data/voices.json`.
5. У сценария появляется кнопка **«🤖 Озвучить: <голос> (N симв.)»** и, если голосов несколько, **«🗣 Озвучить другим голосом»** (только для этого ролика). Каждая фраза озвучивается отдельно, дорожка собирается с ровными паузами и приходит на подтверждение, как ручная запись. Ручная запись остаётся рядом.

- Одинаковый текст с теми же настройками берётся из кэша и символы не тратит. «🔁 Другой дубль» озвучивает заново (спишет символы).
- Произношение исправляет словарь `assets/pronunciation.json` (например, «ДТП» → «дэ-тэ-пэ»; «ПДД» читается как есть); свой дополняет его: `data/pronunciation.json`. В субтитрах слова остаются как есть.
- Без бота: `ELEVENLABS_API_KEY=... node scripts/clone-voice.mjs "Мой голос" запись.mp3`, затем `ELEVENLABS_VOICE_ID` в `.env`. Проверить озвучку: `node scripts/tts-sample.mjs "Текст" out.mp3`.
- Автотест на имитации ElevenLabs: `node test/e2e-tts.mjs`.

## Командная строка

```bash
npm install && sh scripts/setup.sh                 # зависимости + модель шумоподавления
npm run render -- scenarios/q01_ravnoznachny.json --preview                 # черновик 540x960, голос оценивается по тексту
npm run render -- scenarios/q01_ravnoznachny.json --voice моя_запись.m4a    # с вашим голосом (720p)
npm run render -- scenarios/q01_ravnoznachny.json --fhd --voice запись.m4a  # 1080x1920
npm run render -- scenarios/q01_ravnoznachny.json --frames 3,10,20          # только PNG-кадры для отладки сцены
npm run render -- scenarios/q13_levo_svetofor.json --range 15-27            # кусок ролика (без звука) для быстрого просмотра
```
Нужны Node 20+, ffmpeg и Chromium (`CHROMIUM_PATH`, по умолчанию `/opt/pw-browsers/chromium`).

## Свои 3D-модели (машины и люди)
Файлы `.glb` кладутся в `assets/models/`, описание — в `assets/models/models.json`, в сценарии у объекта — `"model": "имя"`.
```json
"lada_vesta": { "file": "cars/lada_vesta.glb", "length": 4.4 },
"man_jacket": { "file": "people/man_jacket.glb", "height": 1.78, "walk": "walk", "idle": "idle" }
```
- **Модели по умолчанию:** `_defaults` в `models.json` — по типу объекта: `car` (VW Passat и BMW M5 по очереди, в цвете `color` из сценария), `truck` (ЗИЛ-131), `bus` (МАЗ-203), `tram` (КТМ-5). `"model": "procedural"` — самодельная модель.
- **Трамвай:** тип объекта `tram`; рельсы рисуются по `"scene": { "tram": { "road": "z" | "x", "tracks": [-2, 2] } }` (смещения осей путей от оси дороги, м) (колея 1520 мм).
- Поля описания машины: `length` (м), `wheels` (шаблон имён колёс), `paint` (материал кузова для перекраски), `lights` (стоп-сигналы), `blinkers` (оранжевые стёкла поворотников; где их нет — мигает часть стоп-фонаря), `simplify` (`{"шаблон узла": доля треугольников}`, например салон), `hide` (скрыть узлы), `glassOpacity`, `wheelSplit` (колёса слиты с кузовом в один меш — имя этого меша; колёса вырезаются по геометрии), `merge: false` (не объединять детали). При загрузке детали с одинаковым материалом объединяются (меньше вызовов отрисовки), «честное» преломление стёкол заменяется тонировкой.
- **Машины:** нос модели определяется по колёсам (имена узлов с `front`/`back`), иначе задайте `"forward": "+x" | "-x" | "+z" | "-z"`. Колёса (узлы `wheel|tire|tyre`, шаблон — `"wheels"`) крутятся и поворачиваются, кузов приседает при торможении, поворотники добавляются по углам. Стоп-сигналы — материалы с именами `tail|brake|stop|rear light` (шаблон — `"lights"`).
- **Люди:** модель со скелетом и клипами ходьбы и покоя (например, Mixamo). Шаг привязан к пройденному пути. Лицо модели по умолчанию смотрит в `+z` (как у Mixamo), иначе `"forward"`.
- Проверка сценария сообщит, если модели нет в `models.json`.
- Пример (CC0): машины из Kenney Car Kit — `kenney_sedan`, `kenney_police`, `kenney_ambulance`.
- Дорожные знаки — наборы «Modular Russian Road Signs Pack (URBAN)» (Unka II) и «Модульный набор дорожных знаков (Дополнение)» (Staks), CC-BY 4.0. Зебры по умолчанию бело-жёлтые, `"crosswalks": [{"road": "z", "at": 0, "style": "white"}]` — только белые.
- Лицензии моделей — поле `license` в `models.json`. ЗИЛ-131, МАЗ-203, КТМ-5 — CC-BY 4.0 (коммерческое использование можно, автора указать в описании ролика); VW Passat и BMW M5 — CC-BY-NC-SA (только некоммерческое).

## Формат сценария

Время в сценарии указывается **не секундами, а якорями на фразы озвучки**, поэтому любая запись голоса ложится на видео:
`"p3"` начало 3-й фразы · `"p3.end"` её конец · `"p3+1.5"` / `"p3.end-0.3"` со сдвигом · `"end"` конец ролика. Фразы нумеруются с 1; числа (секунды) тоже допустимы.

| Поле | Что делает |
|---|---|
| `tag`, `title` | плашка сверху и название |
| `voiceover` | фразы озвучки (она же субтитры); `noCaption: true` скрывает субтитр (хук, призыв). Цвет в тексте: `[y]` `[g]` `[r]` |
| `scene.roads` | `["x","z"]` перекрёсток · `["z"]` одна дорога · `scene.crosswalks`: `z` зебр |
| `scene.crosswalks` | число: зебра через дорогу вдоль z на этой координате; или `{road: "x"\|"z", at: число}` (на перекрёстке с зебрами стоп-линии отодвигаются) |
| `scene.lights` | светофоры: `{pos: [x, z], rot, state: "red"\|"yellow"\|"green"\|"off"}` |
| `trails` | линия траектории, рисуется постепенно по будущему пути объекта: `{ "target": "truck", "pathT0": "p8", "pathT1": "p8+5", "t0": "p7", "t1": "p7.end", "color": "0x34d058", "draw": 1.8, "width": 1.1 }` |
| `decals` | схема таблички 8.13 «прилетает» к камере и ложится на перекрёсток: `{ "roads": { "main": ["top", "right"], "minor": ["bottom", "left"] }, "t0": "p6", "t1": "p7.end", "fly": 2.6, "size": 26, "opacity": 0.5 }` (top — впереди, bottom — откуда едем) |
| `card.notes` | плашки под карточкой вопроса: `[{ "text": "Пиши в [y]комментариях[/y]", "t0": "p2", "t1": "p2.end" }]` |
| `scene.style` | `"clean"` (по умолчанию) — чистая стилизованная картинка: ровный асфальт, красная плитка, яркий газон, мультяшные деревья, светлые дома; `"real"` — фотореализм (текстуры Poly Haven, процедурные деревья) |
| `plate`, `sticker` (у объекта) | российский номер спереди и сзади: `"plate": "Е777КХ77"`; наклейка со значком Telegram на заднем стекле: `"sticker": "@litepdd"`. Работает с моделями из `models.json`; высоту номера сзади/спереди можно уточнить полями `plateRear` / `plateFront` (м) у модели |
| `scene.signs` | `type` — знак из каталога `src/web/world/sign-catalog.js` (около 40 знаков ПДД: `main_road`, `end_main_road`, `yield`, `stop`, `ped_crossing`, `no_left`, `no_entry`, `one_way`, `bus_stop`…); `pos: [x, z]`; `rot`; `size` (диаметр круглого знака, по умолчанию 0,8 м); `plate` — табличка под знаком (`main_direction` — 8.13, `zone_100`, `truck`…), `plateFlip: true` — отразить; `plateRoads: { "main": ["top", "right"], "minor": ["bottom", "left"] }` — табличка 8.13 с любой схемой главной дороги |
| `objects` | `type`: `car`, `bus`, `truck`, `pedestrian`; `model` — своя 3D-модель (раздел выше); `color`; `path`: точки `{t, x, z, ease?, ctrl?}` (`ctrl` изгибает отрезок: поворот); `heading` (градусы) для стоящих; `appear: true` — виден только во время движения; `blinker: {side, t0, t1}` — поворотник |
| `highlights`, `routes` | кольцо вокруг объекта · подсвеченная линия на земле |
| `camera` | ключевые кадры `{t, pos, look, fov}` или слежение `{t, follow: "me", offset: [вперёд, вверх, вправо], look: "id" \| [x,y,z], lookOffset, focus: "id", fov}`; `cut: true` — монтажная склейка вместо плавного перелёта |
| `hooks`, `labels` | крупный текст-«крючок» · подписи над объектами |
| `card` | карточка вопроса: `windows` (когда видна), `reveal`, `correct` (номер с 0). Либо текстом (`question`, `answers`), либо картинкой билета: `image` (путь или data-URI) и `correctRect` `[x, y, ширина, высота]` в долях картинки: подсвечивает правильный ответ |
| `cta` | финальный призыв |
| `music` | `false` — без фоновой музыки в этом ролике |

Координаты в метрах: `x` вправо, `z` на зрителя, `y` вверх. Движение правостороннее: полоса `x=+2` едет на север, `x=-2` на юг, `z=+2` на восток, `z=-2` на запад.
Сценарий проверяется до рендера, ошибки выводятся понятным списком.

## Картинка вопроса
Картинка билета вставляется в видео как карточка, правильный ответ подсвечивается зелёной рамкой. Чтобы сценарий можно было прислать боту одним файлом, картинку вшивают в него:
```bash
node scripts/embed-image.mjs scenarios/q13_levo_svetofor.json   # → ready/q13_levo_svetofor.json
```

## Голос: очистка записи
Режим задаётся `VOICE_CLEAN`: `off` (по умолчанию: только срез низов, тембр не меняется), `light` (срез низов и очень мягкое шумоподавление), `full` (шумодав RNNoise, коррекция тембра, компрессия: для шумных записей). Во всех режимах громкость итоговой дорожки выравнивается до −16 LUFS. Эхо комнаты полностью не убирается, поэтому записывайтесь в небольшой комнате с мебелью/шторами, микрофон в 15–20 см ото рта.
